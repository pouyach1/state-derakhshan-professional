# املاک درخشان — نسخه حرفه‌ای

وب‌سایت نمایشگاهی و پریمیوم برای آژانس املاک درخشان.

## اجرا

```bash
npm install
npm run dev
```

## ساخت تولید

```bash
npm run build
npm run preview
```

## صفحات

- `/` خانه
- `/properties` فهرست املاک
- `/properties/:slug` جزئیات ملک
- `/about` درباره ما
- `/contact` تماس

داده‌های املاک به‌صورت استاتیک در `src/data/properties.js` نگهداری می‌شوند.
